## Веб-приложение с интегрированным AI-агентом для улучшения описания объявления

Личный кабинет продавца с интегрированным AI-ассистентом, который помогает улучшать описания объявлений. Продавец видит список своих объявлений, выбирает нужное и может просмотреть карточку товара, перейти к редактированию и запросить рекомендации от нейросети. Сервис анализирует содержимое карточки товара и предлагает улучшения текста. 

Серверная часть была дана по условиям ТЗ, frontend полностью реализован мной
Описание задания, макеты Figma, документация по серверной части находятся по ссылке [документация](https://github.com/avito-tech/tech-internship/blob/main/Tech%20Internships/Frontend/Frontend-trainee-assignment-spring-2026/Frontend-trainee-assignment-spring-2026.md#документация-по-серверной-части)

## Структура папок и файлов
Каждая папка с компонентом содержит два файла с расширениями tsx (функциональный компонент) и css (стили для этого компонента)

  ```
src/
├── App/                  # корневой компонент, роутинг
├── components/
│   ├── AdItem/           # карточка объявления со страницы всех объявлений
├── pages/
│   ├── Ad/                # страница объявления (подробная информация: цена, название, характеристики, описание)
│   ├── AdEdit/            # страница с формой редактирования объявления
│   ├── AdList/            # список всех объявлений, фильтрация, поиск, пагинация        
├── types.ts               # типы и интерфейсы, функции для русифицирования категорий и названий
└── main.tsx
```
