# Веб-приложение с интегрированным AI-агентом для улучшения описания объявления

Личный кабинет продавца с интегрированным AI-ассистентом, который помогает улучшать описания объявлений. Продавец видит список своих объявлений, выбирает нужное и может просмотреть карточку товара, перейти к редактированию и запросить рекомендации от нейросети. Сервис анализирует содержимое карточки товара и предлагает улучшения текста.

Серверная часть была дана по условиям ТЗ, frontend полностью реализован мной.

Описание задания, макеты Figma и документация по серверной части находятся по ссылке: [документация](https://github.com/avito-tech/tech-internship/blob/main/Tech%20Internships/Frontend/Frontend-trainee-assignment-spring-2026/Frontend-trainee-assignment-spring-2026.md#документация-по-серверной-части)

## Возможности

- **Список объявлений** с двумя режимами отображения: сетка и ряды
- **Поиск** по названию
- **Фильтры**: по категориям (несколько сразу) и переключатель «Только требующие доработок»
- **Сортировка**: по названию и по новизне
- **Пагинация** (при смене фильтров, поиска, сортировки или режима отображения страница сбрасывается на первую)
- **Скелетоны** для корректной загрузки, повторяют выбранный режим отображения
- **Экран ошибки** с кнопкой «Повторить», если список не загрузился
- **Просмотр объявления** по ссылке `/ad/:id`
- **Редактирование объявления** с динамическими параметрами в зависимости от категории
- **AI-помощник**: рекомендация рыночной цены и генерация описания по данным формы
- **Черновик формы** редактирования (восстанавливается при повторном открытии)

## Установка и запуск

Нужен Node.js (рекомендуется LTS).

### 1. Клонирование

```bash
git clone https://github.com/plovaks/AI-assistant-for-personal-account.git
cd AI-assistant-for-personal-account
```

### 2. Переменные окружения

Перед запуском создайте два файла `.env`, подробности в разделе [Переменные окружения](#переменные-окружения).

### 3. Запуск сервера

Сервер нужно запускать первым, фронтенд берёт с него данные.

```bash
cd server
npm i
npm start
```

### 4. Запуск фронтенда

В новом окне терминала:

```bash
cd frontend
npm install
npm run dev
```

После запуска приложение откроется на `http://localhost:5173` 

## Переменные окружения

Файлы `.env` в репозиторий не коммитятся.

### Фронтенд (`frontend/.env`)

Создайте файл `.env` в папке `frontend` и укажите адрес сервера:

| Переменная | Описание | Пример |
|------------|----------|--------|
| `API_URL` | Адрес бэкенда, на который проксируются запросы `/items` | `http://localhost:8080` |

### Сервер (`server/.env`)

Ключ нужен только для AI-функций. Зайдите на сайт Ollama, создайте свой бесплатный ключ, затем создайте в папке `server` файл `.env` с переменной `OLLAMA_API_KEY`:

| Переменная | Описание | Пример |
|------------|----------|--------|
| `OLLAMA_API_KEY` | Ключ Ollama для AI-подсказок (цена и описание) | `your_ollama_api_key` |

> **Без ключа** приложение работает полностью: список, фильтры, просмотр и редактирование объявлений. Не будут работать только две AI-кнопки: оценка рыночной цены и генерация описания.

## Структура папок и файлов

Каждая папка с компонентом содержит два файла: `tsx` (функциональный компонент) и `css` (стили этого компонента).

```
src/
├── App/                    # корневой компонент, роутинг
├── components/
│   └── AdItem/             # карточка объявления со страницы всех объявлений
├── assets/                 # папка с изображениями
├── stores/
│   ├── adDetails.store     # загрузка и обновление одного объявления
│   ├── adEditUi.store      # состояние формы редактирования и AI-подсказок
│   ├── adsui.store         # UI-состояние списка: режим, поиск, фильтры, сортировка, страница
│   └── items.store         # загрузка списка объявлений
├── pages/
│   ├── Ad/                 # страница объявления (цена, название, характеристики, описание)
│   ├── AdEdit/             # страница с формой редактирования объявления
│   └── AdList/             # список всех объявлений, фильтрация, поиск, пагинация
├── types.ts                # типы и интерфейсы, функции для русификации категорий и названий
├── aiResponses.ts          # запросы к AI: оценка цены и генерация описания
└── main.tsx
```

## Как устроен стейт

- `adsUiStore` хранит всё, что пользователь выбирает в списке. `itemsPerPage` и `skip` вычисляются из режима отображения и текущей страницы
- `itemsStore` по этим параметрам запрашивает данные. `useEffect` в списке перезапрашивает их при изменении любого параметра
- `adDetailsStore` отвечает за одно объявление: загрузка (`fetchAdById`) и сохранение (`updatedAd`)
- `adEditUiStore` держит черновик формы и состояния AI-запросов
